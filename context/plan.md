# Implementation plan

1. Maintain the isolation and licensing gates.
2. Prepare and checksum public BANKING77 files.
3. Validate the teacher API on synthetic text only.
4. Produce versioned hard and soft teacher records from training data only.
5. Compare zero-shot, few-shot, hard, soft, hybrid, full-supervision, and
   large-encoder references.
6. Package long-running operations as recoverable asynchronous jobs.
7. Promote models only through metric, calibration, latency, lineage, and
   security gates.
8. Generate recruiter-facing claims only from validated artifacts.
